# Jupyter Notebook to PDF — Docker One-File Instructions

######################################################################
################# STEPS TO DO IN LOCAL ENVIRONMENT ###################
######################################################################

## Step 1 — Build Docker Image

Run from project root:

```
docker build -t ipynb-pdf .
```

(First time takes ~3–5 minutes)

---

## Step 2 — Convert ALL Notebooks to PDF

```
docker run --rm \
  -v "$(pwd)":/home/jovyan/work \
  ipynb-pdf \
  bash /home/jovyan/work/code/ipynb_to_pdf.sh /home/jovyan/work/code 
```
